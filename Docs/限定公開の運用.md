# 匿名限定試用の運用

公開対象は `apps/worker/wrangler.jsonc` の `webflipper` Worker、`webflipper-canvas` R2 Standardバケット。Workerと2個のSQLite-backed Durable Object、静的アセットを同じアカウントに配置する。

## 公開と更新

```powershell
pnpm typecheck
pnpm test
pnpm test:e2e
pnpm build:worker
pnpm test:worker:e2e
pnpm test:trial:e2e
pnpm deploy:trial
```

`deploy:trial` は初回だけランダムな試用コードを生成し、`apps/worker/.wrangler/trial-secrets.json` へ保存する。Git管理外のこのファイルを手元で開き、`TRIAL_CODE` の値を招待する相手にだけ共有する。値はコマンド引数・ログ・Gitへ出さず、Wranglerの `--secrets-file` でSecretとして送る。ファイルを削除して再実行すればコードが変わり、既存の試用認証も無効になる。

R2は公開アクセスを有効にしない。新規作成時の設定:

```powershell
pnpm --filter @webflipper/worker exec wrangler r2 bucket create webflipper-canvas --location apac --storage-class Standard --update-config false
pnpm --filter @webflipper/worker exec wrangler r2 bucket lifecycle add webflipper-canvas orphan-safety --expire-days 1 --force
```

既存バケットに対して作成コマンドを再実行する必要はない。

## 利用停止

入口を閉じる場合は以下で `TRIAL_MODE=closed` を配置する。既存ルームの終了・掃除用Alarmは継続する。

```powershell
pnpm --filter @webflipper/worker exec wrangler deploy --var TRIAL_MODE:closed
```

`pnpm deploy:trial` で設定ファイルの `on` に戻る。`off` はローカルの標準E2E用であり、公開先では設定しない。

## 検証と監視

GitHub Actionsは型検査・単体/統合テスト・Fake構成のE2E・ローカルWrangler E2E・試用コード付きE2Eを実行する。本番バインディングへテストを書き込まない。実公開後の最小確認は別工程とする。

CloudflareダッシュボードでWorkersとDurable Objectsの日次使用量、R2の保存量と操作回数を確認する。入口の拒否や他アプリによる消費も含めて確認する。アプリ側上限と限界は [ADR 0006](ADR/0006-limited-free-trial.md) を参照。

ログへ回答や名前、Cookie、試用コードを出さない。現状は少量の診断ログをサンプリングする。保持期間はCloudflareプランの設定に従い、アプリの7日保持要件を満たしたと扱わない。

GitHubからの自動デプロイは未設定。実行環境のOAuthをGitHubにコピーしない。Workers Buildsで当リポジトリを接続するか、別途権限を絞ったCI用API TokenをSecret登録する必要がある。
