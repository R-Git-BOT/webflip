# WebFlipper 開発方針

## テスト駆動開発

新機能、仕様変更、バグ修正は、導入済みの `tdd` スキルに従ってテスト駆動開発で進める。

1. 次に実現する振る舞いを1文で定義する。
2. その振る舞いを観測するSeamと公開Interfaceを明示する。
3. 最小のテストを1つ書き、意図した理由で失敗することを確認する（Red）。
4. そのテストを通す最小限のImplementationだけを追加する（Green）。
5. 全テストがGreenであることを確認する。
6. 次の振る舞いについて同じサイクルを繰り返す。
7. リファクタリングはGreenの状態で行い、振る舞いを変更しない。

実装を先にまとめて作ってからテストを追加する進め方は採用しない。テストは内部Implementationではなく、利用者または呼び出し元から観測できる振る舞いを検証する。

## Cloudflare依存の代替方針

通常のRed・Greenサイクルと自動テストでは、Cloudflareのアカウント、リモート開発環境、本番Bindingへ接続しない。CloudflareとのSeamには、同じInterfaceを実装するインメモリのFake Adapterまたは外部応答を固定するStubを使用する。

ユーザーが「モック」と呼ぶ代替物は、次の外部依存に限定する。

- Durable Objectの保存に対するインメモリRoomStore Adapter
- Durable Object Alarmに対するFakeClockとFakeDeadlineScheduler
- WebSocket Hibernationに対するFakeConnectionHub
- WorkerのCookie・セッションに対するインメモリSessionStore Adapter
- Cloudflare上の一時バイナリ保存に対するインメモリBlobStore Adapter
- Discord OAuthに対するStub Discord Adapter

`RoomEngine`、Canvas Module、入力検証などWebFlipper自身が所有するModuleはモックしない。テストはAdapterの呼び出し回数ではなく、公開Interfaceから観測できる状態、結果、イベント、エラーを検証する。

Cloudflare実環境での確認はTDDのRed・Greenサイクルへ含めない。リリース候補に対してのみ、別のステージング環境で最小限のスモークテストを行う。通常の実装完了条件はCloudflareへの接続なしで満たせるものとする。

## 合意済みのテストSeam

### `RoomEngine` Interface

コマンドを受け取り、結果、状態、イベントを返すInterfaceを検証する。ラウンド遷移、対象参加者、同時確定、退出、除外、タイマー、正解回数をここで扱う。HTTP、WebSocket、Durable Object、R2の詳細は検証対象に含めない。

### Canvas Interface

描画操作を受け取り、描画操作履歴、Undo・Redo状態、PNGを返すInterfaceを検証する。DOMイベント配線や画面レイアウトはこのSeamに含めない。

### 通信契約Interface

信頼できないHTTP・WebSocket入力を受け取り、型付けされたコマンドまたは検証エラーを返すInterfaceを検証する。

### 実行時Adapterの契約Seam

インメモリRoomStore、FakeDeadlineScheduler、FakeConnectionHub、インメモリSessionStore、インメモリBlobStoreを組み合わせ、Cookie、セッション、期限、再生成後の復元、コマンドの冪等性、状態リビジョン、切断復帰を検証する。Cloudflareのクラスを直接生成せず、実行時Adapterが満たすInterfaceをテスト面とする。内部関数の呼び出し回数は検証しない。

### ブラウザSeam

Playwrightからホストと複数参加者を操作し、ルーム作成から結果公開・次ラウンド・終了までの重要な利用者フローを検証する。すべてのドメイン分岐をブラウザテストで重複検証しない。

### Discord Adapter

Discordは外部システムなので、OAuth応答を置き換えるテストAdapterを使用する。通常の自動テストから実際のDiscordへ接続しない。

## 完了時の証拠

実装完了報告には、少なくとも次を含める。

- 最初に失敗したテストと、その失敗理由
- Greenへ移行した対象の振る舞い
- 実行した単体・統合・ブラウザテスト
- 使用したFake・Stub Adapterと、Cloudflareへ接続していないこと
- 未検証の範囲と残っているリスク
